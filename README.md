# 紙ひこうき郵便局

小学3年生向け。立体的な絵本の街で、ゴムをひく長さを調整して動物に手紙を届けるブラウザゲーム。

- タッチ、マウス、キーボードの矢印キーでゴムの長さを調整。発射は専用ボタン。
- 練習は弱い追い風で固定。3軒へ届けると冒険へ進むボタンが出る。上部のモード選択からも切り替え可能。
- 冒険は配達ごとに風が変化。飛行中と同じ配達の再挑戦では固定し、比較できる。
- 前の着地点、伸ばした長さ、距離を表示。失敗後は再挑戦、成功後は次の配達へ。
- セッション内のみ記録。リロードやモード変更で進行はリセット。個人情報・外部データ送信なし。

## 教材としての位置付け

風とゴムの働きを考えるための簡略化したゲーム。実際の紙飛行機の空力シミュレーションではない。目盛り・歩ぶんはゲーム内の尺度であり実測値ではない。実験結果の証明や評価テストには使わず、授業の車の実験に戻って比較する。

## 開発と確認

`npm install` → `npm run dev`

`npx tsc --noEmit` / `node --experimental-strip-types --test tests/flight.test.ts` / `npm run build`

ゲームの全15通りの届け先・風の組み合わせが整数の目盛りで到達可能であること、飛距離の単調性、練習の一定風、冒険の変化、描画と判定の座標整合性を検証。

街の絵は組み込み image_gen で1回生成。プロンプトは ASSET_PROMPT.txt。UIは依存ライブラリのアイコンとコンポーネント。追加の外部フォントは使用しない。

WebMCPは対応ブラウザで状態読み取り・発射・次の配達を登録する。非対応環境では無効。対応検証コンテキストがないため、WebMCP契約の実機確認は未実施。ブラウザの画面・クリック試験と実タブレットでの操作確認は未実施。
